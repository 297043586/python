# 第十九批更新说明

## 按品牌配置温度告警阈值

- 「设置 → 厂商 / OID」每个品牌新增温度预警阈值和严重阈值（摄氏度）；支持内置的华为、H3C、锐捷、Cisco，也支持新增的自定义品牌。
- 温度达到预警阈值产生风险告警，达到严重阈值产生严重告警。保存时校验阈值范围，并要求严重阈值高于预警阈值；保存后下一轮巡检生效。
- 所有现有配置沿用此前固定的 60℃ / 70℃默认值，避免升级后改变告警行为。由于具体阈值随设备型号和传感器位置不同，未擅自填入品牌统一值；可依据对应型号手册或设备告警规范分别调整。

## 升级与构建

- 替换 `netmon.exe` 并重启程序。设置保存在 `data/vendors.json`，旧版已保存的厂商 OID 会自动补上 60℃ / 70℃阈值。
