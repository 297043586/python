# 第十七批更新说明

## 电转光模块误报光衰

- 锐捷厂商配置新增标准 `MAU-MIB::ifMauType`：`.1.3.6.1.2.1.26.2.1.1.3`。它返回 MAU 类型对象标识符，平台按 IANA 标准识别已知铜缆类型（包括 1000BASE-T 的 29/30）并跳过对应端口的 RX/TX 光功率哨兵值。
- OID 可在「设置 → 厂商 / OID → 锐捷 → 标准 MAU-MIB ifMauType OID」查看、测试和编辑。旧版锐捷配置会自动继承该默认项；设备没有暴露此表时会忽略，不影响其他光功率来源。
- 若设备仍显示 `-40 dBm`，在锐捷 CLI 执行 `show snmp mib`，确认是否列出 `ifMauEntry` / `ifMauType`；也可在设置页选该设备，对上述 OID 点「试一下」。未暴露标准 MAU 表的型号仍需其 MIB 文件或 SNMP walk 输出才能确认私有介质类型 OID，不预置未经核实的厂商私有值。
- H3C 当前 / 旧版收发器介质 OID 与华为 `hwEthernetPortMode` 仍按各自整数枚举识别，数值配置和 OID 都保留在「厂商 / OID」设置中。
